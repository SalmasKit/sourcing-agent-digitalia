# Targetalent — Observability & Monitoring Stack

The observability and runtime telemetry infrastructure for **Targetalent** (*Target Talent*), built for **Digitalia Solutions**.

This stack provides real-time metrics scraping, alerting thresholds, and visual operational dashboards across the Spring Boot backend, Python AI agent, and database layers using **Prometheus** and **Grafana**.

## Scrape Configuration (`prometheus.yml`)

Prometheus is configured to scrape the Spring Boot actuator endpoint with authenticated Basic Auth:

```yaml
global:
  scrape_interval: 15s

scrape_configs:
  - job_name: 'sourcing-backend'
    metrics_path: '/actuator/prometheus'
    scrape_interval: 10s
    static_configs:
      - targets: ['backend-spring:8080']
    basic_auth:
      username: prometheus
      password_file: /tmp/prometheus-secrets/password
```

## Key Monitored Metrics

### 1. JVM & System Health (Spring Boot)
- `jvm_memory_used_bytes` / `jvm_memory_max_bytes`: Heap and non-heap memory consumption.
- `jvm_threads_live_threads`: Active virtual and platform threads.
- `process_cpu_usage` & `system_cpu_usage`: CPU utilization.
- `hikaricp_connections_active` / `hikaricp_connections_idle`: PostgreSQL connection pool saturation.

### 2. HTTP & Traffic Performance
- `http_server_requests_seconds_count`: Total request throughput per route.
- `http_server_requests_seconds_sum` / `_count`: Average and p95/p99 response latency.
- `http_server_requests_seconds_bucket{status=~"5.."}`: HTTP 5xx error rate tracking.

### 3. Business & Security Operations
- **Rate Limiter Invocations:** Rate of `429 Too Many Requests` responses generated by Bucket4j.
- **Search Sourcing Lifecycle:** Latency distribution of AI searches (`PENDING` → `COMPLETED`).
- **WebClient Downstream Calls:** Timeout and retry counters when connecting to `agent-service`.

## Running the Observability Stack

The observability services are orchestrated via the root `docker-compose.yml`:

```bash
# Start Prometheus and Grafana together
docker compose up -d prometheus grafana

# Inspect logs
docker compose logs -f prometheus
docker compose logs -f grafana
```

Once started:
1. Navigate to Grafana at `http://localhost:3001`.
2. Log in using `admin` / `admin`.
3. Explore the pre-provisioned dashboards under the **Targetalent** folder.
